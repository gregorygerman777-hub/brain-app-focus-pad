# Focus Pad

A quiet full-screen writing pad with autosave, word count and a timer.

A brain app for [BRAINF](https://github.com/gregorygerman777-hub/BRAINF). It runs as a tab
(`/pad`) inside your brain and talks to it through the console's app bridge.

- Permissions: `memory.write`
- Memory layers: episodic (append)

## Install

In your brain: **Settings > Apps**, paste
`https://github.com/gregorygerman777-hub/brain-app-focus-pad` and approve.

## Files

- `brain-app.yaml`: the manifest (`brain-app/v1`)
- `dist/index.html`: the whole app, no build step
